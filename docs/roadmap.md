# План разработки Random Map Creation (TI4)

## Архитектурное видение
1. **Backend:** Socket.io (real-time синхронизация), хранение состояния комнат.
2. **Frontend:** React + гексагональная сетка (например, SVG или библиотека).
3. **Состояние:** ID комнаты, список игроков, настройки, состояние поля, очередность хода.
4. **Claim-система:** `localStorage` для ID игрока + серверная верификация в БД.

---

## Этапы разработки

### Этап 1: Структура и Комнаты (MVP)
*   **Задача:** Генерация уникальных URL (`/room/:id`).
*   **Функционал:** Страница настроек, создание комнаты, присоединение, логика "Claim".

### Этап 2: Визуализация поля и Тайлы
*   **Задача:** Отрисовка гексагональной сетки (3 кольца).
*   **Функционал:** Система инвентаря, логика случайной выдачи тайлов (баланс по тирам).

### Этап 3: Движок правил и Snake-очередь
*   **Задача:** Реализация Snake-порядка ходов.
*   **Функционал:** Валидация размещения (кольца, аномалии, червоточины), передача хода.

### Этап 4: Финализация
*   **Задача:** Режим просмотра готовой карты.
*   **Функционал:** Сохранение итогового состояния и отображение карты.

---

## Рекомендации
*   Использовать JSON-конфиг для описания всех тайлов.
*   Серверная проверка всех действий (не доверять клиенту).
